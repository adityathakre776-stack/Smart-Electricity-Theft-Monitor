1
Install Mosquitto MQTT Broker on Windows
Download → Install → Run as service
Windows ▼

Mosquitto is a free, lightweight MQTT broker that runs on your PC. The ESP32 will send sensor data to this broker.

  • 1
    Go to https://mosquitto.org/download/ → Click Windows installer (.exe) → Download and run it
  • 2
    Accept defaults during installation. Default install path: C:\Program Files\mosquitto\
  • 3
    Open Notepad as Administrator → Open file: C:\Program Files\mosquitto\mosquitto.conf
  • 4
    Add these 4 lines at the very bottom of mosquitto.conf and Save:
listener 1883 allow_anonymous true listener 9001 protocol websockets
ℹ
Port 1883 = for ESP32 MQTT. Port 9001 = for Web Dashboard (WebSocket). Both needed!
  • 5
    Open Command Prompt as Administrator and run:
net stop mosquitto net start mosquitto
  • 6
    Verify broker is running — you should see Status: Running:
sc query mosquitto
✔
If you see STATE: RUNNING — broker is ready! Move to Step 2.
2
Find Your PC's IP Address
Get the IP to paste into ESP32 code
Windows ▼

The ESP32 needs your PC's IP address to connect to the MQTT broker. Run this command:

ipconfig
  • 1
    Look for IPv4 Address under your WiFi adapter
  • 2
    It will look like: 192.168.1.105 (your actual number will differ)
  • 3
    Make sure your ESP32 and PC are on the same WiFi network (same router)
⚠
Your current IP shown here (detected from browser): Detecting... — Use this in the ESP32 code!
ℹ
If using a PC mobile hotspot (like NayanSathi project), your IP is usually 192.168.137.1
3
Open Windows Firewall for MQTT Ports
Allow ESP32 to reach the broker through firewall
Windows ▼

Windows Firewall blocks incoming connections by default. Run these commands in Command Prompt as Administrator:

netsh advfirewall firewall add rule name="MQTT 1883" protocol=TCP dir=in localport=1883 action=allow netsh advfirewall firewall add rule name="MQTT WS 9001" protocol=TCP dir=in localport=9001 action=allow
✔
Each command should say "Ok." — that means the rule was added successfully.
⚠
If the ESP32 connects to WiFi but MQTT connection fails (RC=-2), it's almost always a firewall issue. Run the above commands.
4
Update ESP32 Code with Your Broker IP
Paste your PC IP into the Arduino sketch
ESP32 Code ▼

Open esp32_direct_noadc.ino in Arduino IDE and find these lines near the top. Edit the IP address:

const char* WIFI_SSID = "Thakre"; // Your WiFi name const char* WIFI_PASS = "KRISHNA2277"; // Your WiFi password const char* MQTT_BROKER = "192.168.1.105"; // ← PUT YOUR PC IP HERE const int MQTT_PORT = 1883;
ℹ
The WiFi credentials are already set. Only change MQTT_BROKER to your PC's actual IP from Step 2.
  • 1
    In Arduino IDE: Tools → Board → ESP32 Dev Module
  • 2
    Tools → Port → select the COM port your ESP32 is connected to
  • 3
    Click Upload (→ arrow button) and wait for "Done uploading"
5
Test MQTT Connection with Serial Monitor
Verify ESP32 connects and publishes data
Arduino IDE ▼

After uploading, open Serial Monitor to verify the connection:

  • 1
    In Arduino IDE: Tools → Serial Monitor (or Ctrl+Shift+M)
  • 2
    Set baud rate to 115200 (bottom right dropdown)
  • 3
    Press ESP32 RST (reset) button — you should see:
╔══════════════════════════════════════════╗ ║ Power Theft Detection — Direct Connect ║ ╚══════════════════════════════════════════╝ [WiFi] Connecting to Thakre.......... [WiFi] ✔ Connected! IP: 192.168.1.xxx [MQTT] Connecting to 192.168.1.105:1883 ... ✔ OK ← GOOD! [SYSTEM] Ready — measuring every 2 seconds ══════════════════════════════════════════ Voltage : 229.87 V Current A : 2.3450 A Current B : 2.3100 A Diff(A-B) : 0.0350 A STATUS : ✔ NORMAL ══════════════════════════════════════════ [MQTT] Published OK
✖
If you see ✖ Failed RC=-2 → Wrong IP or firewall blocking. Re-check Steps 2 & 3.
✖
If WiFi keeps failing → Check SSID/Password spelling in code. Ensure 2.4GHz network (ESP32 doesn't support 5GHz).
✔
If you see Published OK → ESP32 is working perfectly! Move to Step 6.
6
MQTT Explorer — Connect, Subscribe & Test
Full walkthrough: live data + theft simulation
MQTT Explorer ▼

Since you already have MQTT Explorer, here is the complete setup for this project from start to finish.

① Connect to Broker
  • 1
    Open MQTT Explorer → click the Connections button (top left)
  • 2
    Click "+" to create a new connection and fill in:
Field in MQTT ExplorerValue to Enter
NamePower Theft Monitor
Protocolmqtt://
HostYour PC IPv4 (e.g. 192.168.1.105)
Port1883
UsernameLeave empty
PasswordLeave empty
Encryption / TLSOFF — unchecked
Validate certificateOFF — unchecked
  • 3
    Click CONNECT → the left panel fills with a topic tree if broker is running
✔
Green dot + topics in left panel = broker is running and reachable!
✖
Connection timeout → broker not running. Go back to Step 1 and restart Mosquitto.
② Subscribe with Wildcard
  • 1
    In the top search bar of MQTT Explorer, type powertheft/# and press Enter
  • 2
    The # wildcard automatically shows ALL subtopics — no need to add them one by one
  • 3
    With ESP32 running, you will see this topic tree on the left:
📁 powertheft ├─ 📄 moduleA/data → {"device":"A","voltage":229.87,"current":2.3450,"power":538.91} ├─ 📄 moduleB/data → {"device":"B","voltage":229.87,"current":2.3100,"power":530.80} ├─ 📄 alert → {"alert":false,"diff":0.035,"currentA":2.345,"currentB":2.310} ├─ 📄 status → {"status":"online"} └─ 📄 alarm → only appears when THEFT is detected!
ℹ
Click any topic on the left → right panel shows full JSON + value graph over time. Perfect for monitoring current A vs B!
③ Simulate Theft — Publish from MQTT Explorer

Test the full alert system without any hardware using the Publish panel at the bottom of MQTT Explorer:

  • 1
    Bottom Publish panel → Topic: powertheft/alert
  • 2
    QoS = 0  |  Retain = ON (checked)
  • 3
    Paste Theft payload → click PUBLISH → dashboard turns RED instantly
{"alert":true,"diff":0.85,"currentA":2.85,"currentB":2.00,"voltage":230.0,"threshold":0.5,"count":1,"ts":1000}
  • 4
    Publish this to the same topic to reset back to NORMAL:
{"alert":false,"diff":0.02,"currentA":2.02,"currentB":2.00,"voltage":230.0,"threshold":0.5,"count":0,"ts":2000}
✔
If the dashboard reacts (RED/GREEN banner) after publish — your broker, MQTT Explorer, and dashboard are all connected perfectly!

Open Web Dashboard & Connect
See live gauges, charts, and theft alerts
Final Step ▼

The web dashboard connects to Mosquitto via WebSocket (port 9001):

  • 1
    Open XAMPP → Start Apache
  • 2
    Open browser → go to http://localhost/Electricity/
  • 3
    In the MQTT Configuration panel (bottom left), set Broker URL to:
ws://localhost:9001
  • 4
    Click the Connect button → Status dot turns ● green
  • 5
    Gauges and charts start updating live from ESP32 data!
  • 6
    To test without hardware → click ▶ Run Demo Simulation
ℹ
If dashboard can't connect: verify protocol websockets is in your mosquitto.conf and broker was restarted.
